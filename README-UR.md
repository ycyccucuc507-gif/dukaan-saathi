# دکان ساتھی — مکمل ابتدائی Android سورس پروجیکٹ

## ڈیفالٹ برانڈنگ
- ایپ کا نام: دکان ساتھی
- دکان کا نام، فون اور پتہ: پہلی بار ایپ کھول کر خود درج کریں۔ کوئی فرضی فون نمبر استعمال نہیں کیا گیا۔
- لوگو: فی الحال عمومی 🎒 بیگ کا نشان بطور ہیڈر استعمال ہوتا ہے۔ اپنی اصل تصویر والا لوگو اپلوڈ کرنے کی سہولت ابھی اس ورژن میں شامل نہیں۔

## شامل فیچرز
- آف لائن SQLite ڈیٹا بیس؛ رسیدوں پر مصنوعی تعداد کی حد نہیں۔
- دکان کا نام، پتہ، فون محفوظ اور تبدیل کرنا۔
- مرمت، ایک سال کی گارنٹی، فروخت کی رسید۔
- گاہک کا نام/نمبر، تفصیل اور رقم۔
- مرمت کے لیے منفرد چھ ہندسوں کا وصولی کوڈ۔
- گارنٹی کی تاریخ سے ایک سال بعد کی اختتامی تاریخ۔
- اردو وائس ان پٹ Android Speech Recognizer سے۔
- پہلے سے Pair کیے گئے Bluetooth SPP ESC/POS پرنٹرز کا انتخاب۔
- رسیدیں تلاش کرنا اور دوبارہ پرنٹ کرنا۔
- JSON بیک اپ بنانا اور بیک اپ بحال کرنا۔
- مقررہ شرائط: زپ اور کنڈے کی گارنٹی نہیں؛ (کپڑے اور سلائی کی گارنٹی ہے)؛ خریدا ہوا مال تبدیل ہو سکتا ہے۔

## GitHub سے APK
1. GitHub پر نیا Public یا Private repository بنائیں: `dukaan-saathi`
2. ZIP کو Extract کریں۔
3. ZIP کے اندر کی فائلیں (app، .github، build.gradle.kts، settings.gradle.kts وغیرہ) repository کے root میں اپلوڈ کریں۔
4. GitHub میں Actions کھولیں؛ `Build Dukaan Saathi APK` منتخب کریں۔
5. `Run workflow` دبائیں یا main branch پر commit کریں۔
6. کامیاب workflow کے نیچے Artifacts سے `Dukaan-Saathi-APK` ڈاؤن لوڈ کریں۔
7. Artifact ZIP کھولیں اور APK انسٹال کریں۔

## اہم ٹیسٹنگ نوٹس
یہ Android سورس پروجیکٹ ہے، تیار شدہ APK نہیں۔ اس ماحول میں Android SDK/Gradle build چلا کر compile اور hardware test کی تصدیق نہیں کی گئی۔ GitHub Actions کا پہلا build اصل compile check ہوگا۔
- بلوٹوتھ پرنٹنگ کے لیے عام SPP/ESC-POS پرنٹر اور فون کے ساتھ پہلے سے pairing درکار ہے۔ ہر 58mm/80mm ماڈل کی مطابقت یقینی نہیں؛ اصل پرنٹر پر ٹیسٹ کریں۔
- رسید کی چوڑائی فی الحال 384 dots (عام 58mm heads کے لیے) رکھی گئی ہے۔ 80mm کے لیے پرنٹ چوڑائی میں ترمیم درکار ہو سکتی ہے۔
- اردو وائس ریکگنیشن Android سروس پر منحصر ہے؛ آف لائن دستیابی فون کے language packs سے مشروط ہے۔
- لوگو امیج اپلوڈ، مکمل بصری رسید پری ویو، مستقل APK signing، گاہک کے کوڈ کی verify screen اور 80mm خودکار چوڑائی آئندہ اپ گریڈ کے کام ہیں۔
- APK debug signing کے ساتھ بنے گی؛ Play Store یا مستقل تقسیم کے لیے الگ release signing درکار ہے۔
